# TimeLedger

Site pessoal, em HTML, CSS e JavaScript puros, para acompanhar ponto, banco de horas, férias, folgas coletivas e créditos eleitorais, e conferir com o saldo oficial.

- Registra a batida do dia com um botão e importa o espelho de ponto colado ou em CSV.
- Calcula horas extras, horas devidas, faltas e marcações incompletas.
- Avisa quando o seu saldo diverge do oficial.
- Funciona no celular e no computador, pode ser instalado na tela inicial e abre sem internet.

Os dados ficam só no navegador do aparelho (localStorage). Use "Baixar backup" na aba Ajustes de vez em quando.

## Abrir

Dê dois cliques em `index.html`. Para instalar na tela inicial do celular, o site precisa estar publicado em um endereço https.

## Publicar no GitHub Pages

1. Envie todos os arquivos desta pasta para a raiz do repositório.
2. No GitHub, abra Settings, depois Pages, escolha a branch principal e a pasta raiz.
3. Acesse o endereço `https://SEU-USUARIO.github.io/TimeLedger/` no celular e use "Adicionar à tela inicial".
